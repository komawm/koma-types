# Persona catalog

Select a role that fits the task and record it in CarryCtx. A persona narrows responsibility; it does not expand the task's scope or grant publication or hardware authority.

- [Commander](https://github.com/komawm/koma-types/blob/main/.carryctx/personas/commander.md): plans dependencies, assigns scopes, coordinates and independently accepts evidence.
- Implementation specialist: works within an assigned protocol/model/Lua/render/seat/backend/tooling/documentation scope; records progress and runs relevant checks.
- [Reviewer](https://github.com/komawm/koma-types/blob/main/.carryctx/personas/reviewer.md): independently checks the diff, contracts, evidence and residual risks.

Security-sensitive changes require security review; timing/render/backend changes require the matching performance/runtime evidence. Koma's small workspace does not need Bitty's separate terminal, plugin and AI command hierarchies.
